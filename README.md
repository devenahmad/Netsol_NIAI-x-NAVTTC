# Netsol NIAI x NAVTTC

My tasks, worksheets and assignments from the 3-month AI / Machine Learning / Deep Learning training,
run by NAVTTC together with Netsol (NIAI). Everything is organised week by week.

## Repository structure

### `NAVTTC Tasks/` - Python scripts (tasks 01-65)

| Week | Topics |
|------|--------|
| Week_01 | Python basics: input/output, conditions, loops, lists, tuples, strings, sets, dictionaries |
| Week_02 | Functions, exception handling, mean/median/mode, standard deviation |
| Week_03 | NumPy (arrays, indexing, slicing, reshaping, sorting, random) and Pandas (series, dataframes, CSV, cleaning, correlation) |
| Week_04 | NumPy and Pandas, continued |
| Week_05 | Linear and logistic regression |
| Week_06 | Decision tree, SVM, time series |
| Week_07 | Neural network from scratch, MLP, loss functions, NLP (NLTK), CNN on CIFAR-10 |
| Week_10 - Week_12 | Microsoft Azure AI demo (text, vision, speech, translation) |

### `Netsol Tasks/` - Jupyter notebooks and assignments

| Week | Topics |
|------|--------|
| Week 01 | Probability foundations, Assignments 1 and 2 |
| Week 02 | Data structures, data visualization, number plate system |
| Week 03 | Exploratory data analysis (Cars, Online Food Ordering) |
| Week 04 | ML optimization lab |
| Week 05 | Regression challenge, KNN, Naive Bayes, SVM, datasets |
| Week 06 | Decision tree and lecture worksheets |

## Setup

```bash
pip install -r requirements.txt
```

The Azure AI demo needs your own Azure key and endpoint, set as the `AZURE_AI_KEY` and
`AZURE_AI_ENDPOINT` environment variables.

## Tools

Python, NumPy, Pandas, Matplotlib, scikit-learn, TensorFlow/Keras, NLTK, Jupyter, Microsoft Azure AI.
